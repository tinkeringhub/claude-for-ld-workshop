# Claude for L&D Workshop

Materials from a hands-on workshop I ran for the ATD Houston Technology SIG in April 2026. It teaches learning and development professionals how to put Claude to work on real L&D tasks: course objectives, learner personas, style guides, and the rest of the design workflow.

Everything here is free to use under [CC BY 4.0](LICENSE). Borrow it, remix it, run your own version. Just credit me (Tamara Thomas, [tinkeringhub.com](https://tinkeringhub.com)).

## What's in here

| File | What it is |
|------|------------|
| `Claude for L&D Workshop v2.html` | The full slide deck. One self-contained file; open it in any browser. |
| `Claude for L&D Workshop v2-print.html` | Print-friendly version of the deck. |
| `Take-Home Wiki (Standalone).html` | Searchable reference guide: prompts, practice exercises, tools, and inspiration in one place. |
| `Take-Home Pack - Part A (Prompts)` | Prompt templates for common L&D tasks. |
| `Take-Home Pack - Part B (Practice)` | Exercises to try on your own. |
| `Take-Home Pack - Part C (Instructions)` | Setup and how-to instructions. |
| `Take-Home Pack - Part D (Tools)` | Tools worth knowing about. |
| `Take-Home Pack - Part E (Inspiration)` | Ideas and examples to get you going. |
| `Pre-Work Guide.html` | What attendees did before the session. |
| `Activity 1 Sample - *.html` | Sample outputs from the first in-session activity. |

Each Take-Home Pack part comes as both `.html` and `.docx`, so you can edit it in Word.

## Viewing

Download the repo (green **Code** button, then **Download ZIP**) and open any `.html` file in your browser. The print deck, Pre-Work Guide, and Activity samples need `styles.css`, `deck-stage.js`, and the `assets/` folder next to them.

You can also view the deck and wiki online at [tinkeringhub.com/workshop](https://tinkeringhub.com/workshop).
